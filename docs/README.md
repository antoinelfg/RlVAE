# Documentation Directory

This directory contains comprehensive documentation for the RlVAE framework.

## 📁 Directory Structure

### `guides/`
User-facing guides and tutorials:
- **RLVAE_THREE_STAGE_PIPELINE.md**: Complete three-stage pipeline guide
- **DEMO_VISUALIZATIONS_GUIDE.md**: Visualization examples and tutorials
- **FULL_RHMC_TRAINING_GUIDE.md**: RHMC training guide
- **README_STREAMLIT.md**: Streamlit app documentation
- **posterior_adaptation_guide.md**: Posterior adaptation guide

### `development/`
Development and technical documentation:
- **enhanced_kl_implementation_summary.md**: KL divergence implementation details
- **enhanced_kl_summary.md**: KL divergence summary
- **TRAINABLE_METRIC_README.md**: Trainable metric documentation
- **SLURM_PIPELINE_README.md**: SLURM cluster usage
- **new_things.md**: Development changelog

### Root Documentation
Core documentation files:
- **NEW_DEVELOPMENTS_CHANGELOG.md**: Comprehensive feature changelog
- **REPOSITORY_ORGANIZATION_GUIDE.md**: Repository organization guide
- **REPO_ORG_GUIDE.md**: Concise repository organization guide
- **GITHUB_DEPLOYMENT_SUMMARY.md**: GitHub deployment summary

## 🚀 Getting Started

### For Users
1. Start with **RLVAE_THREE_STAGE_PIPELINE.md** for pipeline usage
2. Check **DEMO_VISUALIZATIONS_GUIDE.md** for examples
3. Refer to **FULL_RHMC_TRAINING_GUIDE.md** for advanced training

### For Developers
1. Read **NEW_DEVELOPMENTS_CHANGELOG.md** for recent changes
2. Check **enhanced_kl_implementation_summary.md** for technical details
3. Review **REPOSITORY_ORGANIZATION_GUIDE.md** for contribution guidelines

### For Contributors
1. Follow **CURSOR_RULES.md** in the root directory
2. Check **REPO_ORG_GUIDE.md** for repository organization
3. Review **GITHUB_DEPLOYMENT_SUMMARY.md** for deployment status

## 📝 Documentation Standards

- All new features must be documented
- Use clear, concise language
- Include code examples where appropriate
- Keep documentation up-to-date with code changes
- Follow the established directory structure
