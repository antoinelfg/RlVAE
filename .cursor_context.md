# RlVAE Project Context

This document provides context for AI assistants working on the RlVAE (Riemannian Latent Variational Autoencoder) project.

## 🎯 Project Overview

**RlVAE** is a research framework for Riemannian Latent VAEs applied to longitudinal data. The model learns latent spaces with Riemannian geometry, enabling geometric sampling and flow-based temporal dynamics.

### Key Concepts
- **Riemannian Metric**: Data-dependent metric learned from centroid positions
- **RHMC Posterior**: Riemannian Hamiltonian Monte Carlo for sampling
- **Normalizing Flows**: Transform latent states through time
- **Pushforward Metric**: Transport metric through flows

## 🏗️ Architecture

### Three-Stage Pipeline
1. **Stage A**: Vanilla VAE warmup (encoder/decoder training)
2. **Stage B**: Metric learning (RHVAE-style centroids)
3. **Stage C**: Full RlVAE (flows + RHMC + geometric KL)

### Main Model: `ModularRiemannianFlowVAE`
Location: `src/rlvae/models/modular_rlvae.py`

Key components:
- `EncoderManager`: MLP/CNN encoder architectures
- `DecoderManager`: MLP/CNN decoder architectures
- `MetricTensor`: Riemannian metric computation
- `FlowManager`: Normalizing flow chain
- `RiemannianRHMCPosterior`: RHMC sampling
- `LossManager`: Modular loss computation

## 🔧 Configuration (Hydra)

All configuration is in `conf/config.yaml`. Key sections:

### Model Settings (`settings.model`)
```yaml
latent_dim: 2
n_flows: 7
posterior:
  type: riemannian_rhmc
  rhmc_steps: 1
  rhmc_step_size: 0.005
  rhmc_alpha: 0.13
metric:
  temperature_override: 1.0
  bg_strength: 0.005
  eig_floor_abs: 0.1
losses:
  beta: 0.01
  flow_weight: 0.003
  recon_scale: 255.0
```

### Training Settings (`settings.training`)
```yaml
strategy:
  max_epochs: 75
  gradient_clip_val: 0.5
optimizer:
  lr: 0.0001
```

### Pipeline Settings (`pipeline`)
```yaml
run_stage_a: false  # Skip if pretrained
run_stage_b: false  # Skip if metric exists
run_stage_c: true   # Main training
```

## 🔬 Key Parameters

### RHMC Posterior
- `rhmc_steps`: Number of leapfrog steps (0-5)
- `rhmc_step_size`: Integration step size (0.001-0.01)
- `rhmc_alpha`: Scaling for initial covariance (0.01-1.0)

### Metric
- `temperature_override`: Sharpness of centroids (0.5-5.0)
- `bg_strength`: Background identity weight (0.001-0.1)
- `eig_floor_abs`: Minimum eigenvalue (0.01-0.2)

### Losses
- `beta`: KL weight (0.001-1.0)
- `flow_weight`: Flow regularization (0.0001-0.1)
- `recon_scale`: Reconstruction scaling (1.0-255.0)

## 📊 Metrics to Watch

### Training Metrics
- `train_loss`: Total loss
- `train_mse`: Unscaled reconstruction (comparable across runs)
- `train_kl_loss`: KL divergence
- `train_flow_loss`: Flow regularization

### Validation Metrics
- `val_loss`: Total validation loss
- `val_mse`: Unscaled MSE (primary optimization target)
- `val_recon_loss`: Scaled reconstruction

### RHMC Diagnostics
- `rhmc/half_logdet_z0_mean`: Volume at initial sample
- `rhmc/half_logdet_zF_mean`: Volume after flows
- `rhmc/delta_half_logdet_mean`: Flow compression

## 🚨 Common Issues

### NaN in Training
- Check gradient clipping (`gradient_clip_val`)
- Reduce learning rate
- Increase `eig_floor_abs` for metric stability

### Flow Compression
- Normal behavior: flows compress volume
- Watch `sum_logdet_flow` for extreme values
- Adjust `flow_weight` if needed

### RHMC Instability
- Reduce `rhmc_steps` during training
- Use more steps only at inference
- Check `rhmc_alpha` scaling

## 💡 Development Tips

### Adding New Components
1. Add to `src/rlvae/models/components/`
2. Register in appropriate manager
3. Add config options to `conf/config.yaml`
4. Add tests to `tests/`

### Running Sweeps
1. Define sweep config in `conf/sweep/`
2. Use `wandb sweep` to create
3. Run agents with `scripts/wandb_sweep_agent.py`

### Testing Changes
```bash
# Quick test
python run_experiment.py settings.training.strategy.max_epochs=1 \
    settings.visualization.level=none wandb.mode=offline

# Run tests
python -m pytest tests/ -v
```
